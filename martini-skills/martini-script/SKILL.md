# martini-script — Story and narrative development

## What this skill does

Helps the user build or refine the narrative foundation of their project before
any visual work begins. Output is always text: a script, a scene structure, a beat
breakdown, or voiceover lines — not prompts, not generated shots.

## What this skill does NOT do

- Visual shot composition or prompt writing → use **martini-storyboard** or **martini-shot-generation**
- Subject or character consistency management → use **martini-subjects**
- Image or video generation → use **martini-shot-generation**
- Export or delivery → use **martini-export**

## Common user requests

- "Help me write a short film script."
- "Turn this idea into a 4-shot story."
- "Make this voiceover more cinematic."
- "Condense this story into four 15-second videos."
- "Break this into scenes."
- "Write dialogue for this character."

## How to approach it

### Rough idea → concept
When the user has an idea but not a script, ask: What's the emotional core? Who's
in it? What happens? Then shape it into a short-film structure: setup, turn, and
resolution — compressed for the format (typically 4–8 shots, 30s–2min total).

### Script writing and tightening
Write lean. Every sentence should either advance action or reveal character. For
AI video, shorter beats work better than long monologues — aim for one clear
action or moment per shot. Avoid descriptions of things that can't be shown
visually.

### Voiceover
Voiceover should feel spoken, not read. Short sentences. Natural rhythm. Test it
by reading aloud — if it doesn't feel right out loud, rewrite it. Match the
emotional tone to the intended visual mood.

### Condensing to video format
When converting a longer story to short video: identify the 3–5 most essential
beats, cut everything that doesn't serve those beats, and assume the visuals will
carry subtext that doesn't need to be stated explicitly.

### Breaking into beats
A beat = one moment, one action, one shift. For a 4-shot video, each shot should
carry exactly one beat. List them as numbered sentences, one per shot:

```
1. A woman stands alone at a rain-soaked train platform, staring at her phone.
2. She types a message, hesitates, then deletes it.
3. The train arrives. She doesn't board.
4. She turns and walks back the way she came.
```

## Expected output

- A formatted script, beat list, or voiceover text
- Clear scene or shot labels where relevant
- No generation prompts, no technical Martini parameters

## Handoff

When the narrative is ready, the natural next step is **martini-storyboard** —
turning these beats into a visual shot plan.
